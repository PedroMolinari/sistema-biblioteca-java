# 📚 Sistema Biblioteca Java

Projeto desenvolvido em Java com o objetivo de praticar os conceitos de Programação Orientada a Objetos (POO), estruturas de dados, listas, métodos e interação com o usuário via terminal.

## 🚀 Funcionalidades

* Cadastro de livros
* Cadastro de usuários
* Listagem de livros
* Busca de livros por título
* Empréstimo de livros
* Devolução de livros
* Relatório da biblioteca
* Menu interativo no terminal

## 📂 Estrutura do Projeto

### Livro

Responsável por armazenar as informações de um livro:

* Título
* Autor
* Ano
* Identificador
* Status de disponibilidade

### Usuario

Responsável por armazenar os dados dos usuários:

* Nome
* ID
* Senha

### Biblioteca

Responsável pelas regras de negócio do sistema:

* Cadastro de livros
* Cadastro de usuários
* Busca de livros
* Empréstimos
* Devoluções
* Relatórios

### Main

Responsável pela interação com o usuário através do menu no terminal.

## 📋 Menu do Sistema

```text
1 - Cadastrar livro
2 - Cadastrar usuário
3 - Listar livros
4 - Emprestar livro
5 - Devolver livro
6 - Relatório
7 - Buscar livro
0 - Sair
```

## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido como parte dos meus estudos em Java com foco na aprendizagem de Programação Orientada a Objetos e no desenvolvimento das habilidades necessárias para atuar como desenvolvedor backend Java.

## 📚 Conceitos Praticados

* Classes e Objetos
* Construtores
* Encapsulamento
* Métodos
* ArrayList
* Laços de repetição (`for` e `while`)
* Estruturas condicionais (`if/else`)
* Menu interativo com `switch`
* Organização de código em múltiplas classes
